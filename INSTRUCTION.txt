ЯК ВИКЛАСТИ ДОДАТОК (безкоштовно, GitHub Pages)

1. Розпакуйте архів на телефоні (Файли -> натиснути на архів -> Розпакувати).
   Завантажувати на GitHub треба окремі файли, а не сам архів.
2. Зареєструйтесь на github.com.
3. Створіть репозиторій: "+" -> New repository. Назва: nakopychennia. Позначте Public. Create repository.
4. Add file -> Upload files. Виберіть 8 файлів: index.html, manifest.json, sw.js, icon.svg, icon-192.png, icon-512.png, icon-maskable.png, README.md. Commit changes.
5. Settings -> Pages. У Source виберіть "Deploy from a branch", гілка main, папка / (root). Save.
6. Через 1-2 хвилини сайт буде за адресою:
   https://ВАШ-ЛОГІН.github.io/nakopychennia/
7. Відкрийте адресу в Chrome -> меню (три крапки) -> "Додати на головний екран".

ПЕРШИЙ ЗАПУСК (перевірте)
- Під сумою має з'явитися час оновлення цін і курс USDT/UAH.
- Додайте токен (наприклад DOGE): має з'явитися його ціна.
- Натисніть "Купив", введіть кількість і ціну. Перевірте, що середня ціна й прибуток порахувались.

ЯКЩО ЦІНИ НЕ ЗАВАНТАЖУЮТЬСЯ
Під сумою буде "не вдалося оновити". Тоді ціну токена можна ввести вручну:
натисніть на "ціни нема, натисніть" біля токена. Курс гривні: натисніть на рядок з цінами під сумою.

ОНОВЛЕННЯ ДОДАТКА
Add file -> Upload files, завантажте файли з архіву з тими самими назвами (вони замінять старі). Завантажуйте всі 8 файлів з архіву, зокрема PNG-іконки та sw.js.
Дані на телефоні при цьому не втрачаються.

РЕЗЕРВНА КОПІЯ
Вкладка "Ще" -> розділ "Резервна копія".
"Зберегти файл" кладе копію у "Завантаження" (надішліть її собі в Telegram або в хмару).
"Скопіювати текст" копіює всі дані, їх можна вставити в нотатки.
Якщо Chrome очистить дані сайтів, дані зникнуть, тому робіть копію час від часу.
Відновлення: "Імпорт з файлу" або "Вставити текст".

РЕЖИМ "СХОВАТИ СУМИ"
Кнопка з оком угорі розмиває суми. Кнопки й календар при цьому працюють.
